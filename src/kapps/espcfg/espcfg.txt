espcfg.com reads /ini/espcom.ini, programs the 16550, and writes
the 20-byte UART config (ports + pktMax) into the ESPNET kernel
(like wizcfg / net.ini).

espcfg.com [-S] [-M n]

No args: after SETUART, print kernel UART, firmware version (GETINFO), WiFi, IP, SSID.
-S     silent (for autoexec.bat)
-M n   UART payload cap per BDOS (64..2048); overrides pktMax= in ini
       Default 192 (short DI). Use 2048 for apps that send large buffers.
