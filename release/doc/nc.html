NC - Norton Commander для NedoOS

Версия 0.7 · программа nc.com · настройки ../ini/nc.ini · ассоциации ../ini/nc.ext

Двухпанельный файловый менеджер в духе Norton Commander и nv.com: левая и правая панели, строка подсказок, статусная строка с размером и именем файла, часы в правом верхнем углу активной панели.

Экран

Часы0, справаФормат HH:MM

Активная панель подсвечена. Tab переключает левую и правую панели. В подвале панели отображаются путь, число объектов и суммарный размер; при отметке файлов — количество отмеченных и их суммарный размер.

Основные возможности

Навигация

  • Enter на каталоге — войти; на .. — подняться вверх.
  • Enter на файле — запуск.
  • Сортировка: имя, расширение, размер, время; A–Z / Z–A; LFN sort.

Файловые операции

  • Копирование (F5) — в другую панель или путь; каталоги, отмеченные файлы, дерево; диалог при конфликте имён.
  • Перемещение (^) — аналогично копированию.
  • Переименование (F6), создание каталога (F7), удаление (F8).

Просмотр и редактирование

  • F3 — Viewer (texted.com по умолчанию).
  • F4 — Editor (texted.com по умолчанию). Без флагов /k и /p.

Запуск программ

Цепочка: term.com → cmd.com → программа. Режим Cmd в F9: none, /k, /p.

Отметка

Insert или *. F5, F8 и ^ работают с отмеченными.

Диски

F1 / F2 — выбор диска для левой и правой панели (A–D, IDE E–L, SD M, NeoGS N, USB O).

Командная строка

Ввод с клавиатуы, Shift+Enter — вставить имя файла, Esc — отмена.

Меню F9 → Files

Меню открывается клавишей F9. Выберите пункт Files и нажмите Enter. Настройки действуют на активную панель (левую или правую; переключение — Tab).

ПунктНазначение
NameСортировка по имени файла. Звёздочка * у текущего режима.
ExtensionСортировка по расширению.
SizeСортировка по размеру файла.
TimeСортировка по дате и времени изменения.
A-ZВозрастающий порядок (A→Z, меньше→больше, старые→новые).
Z-AУбывающий порядок.
LFN sortСортировка по полному длинному имени (LFN), а не по короткому 8.3. * — включено.
Read on focusПри возвращении в NC после другой программы заново читать каталоги обеих панелей. Без флага — только перерисовка экрана.
Brief viewКраткий вид панели: только имя и размер (без даты/времени). Общий для обеих панелей.
Cmd: none / /k / /pФлаги для cmd.com при запуске файлов с командной строки ипо Enter на .com/.bat. /k — оставить консоль открытой; /p — «Press any key» после вывода. F3/F4 флаги не используют.

Управление в меню

  • ↑ / ↓ — выбор пункта.
  • ← / → — переключение значения (режим сортировки, направление, LFN, флаги).
  • Enter — применить и закрыть меню. Для Name/Extension/Size/Time/A-Z/Z-A пересортировать список.
  • Esc — закрыть без применения изменений сортировки (если ещё не нажат Enter).

Каталоги (..) всегда вверху списка, затем папки, затем файлы. Изменение Cmd сразу пишется в nc.ini; остальные настройки меню — при выходе F10.

Файл nc.ini

Расположение: ../ini/nc.ini (относительно системного каталога). Читается при старте NC, записывается при F10 (выход) и сразу при смене Cmd в меню. Формат: Ключ=значение, строки с # — комментарии. Имена ключей допускаются в виде LeftPath или left_path.

КлючЗначениеПо умолчанию
CmdFlagРежим консоли: none, k (/k), p (/p). См. меню Files.none
ReadOnFocus1 / 0 — обновлять каталоги обеих панелей при возвращении фокуса в NC.0
BriefView1 / 0 — краткий вид панелей (имя + размер).0
LeftActive1 — активна левая панель, 0 — правая.левая
LeftPathСтартовый каталог левой панели, напр. M:/bin/.M:/bin/
RightPathСтартовый каталог правой панели.M:/test/
LeftSortРежим сортировки левой панели: name, ext, size, time.name
RightSortТо же для правой панели.name
LeftSortDirНаправление: asc (A–Z) или desc (Z–A).asc
RightSortDirНаправление правой панели.asc
LeftSortLfn1 / 0 — сортировка левой панели по LFN.0
RightSortLfnТо же для правой панели.0
HideDrivesБуквы дисков через запятую, которые не показывать в меню F1/F2, напр. J,K,L. Пустая строка — все доступные диски.пусто
ViewerПрограмма просмотра (F3). Запускается с путём к файлу в аргументе.texted.com
EditorПрограмма редактирования (F4).texted.com

Для логических значений 1, 0, y, n, true, false понимаются одинаково. При отсутствии файла или ключа используются значения по умолчанию из таблицы.

Пример nc.ini

# NC settings
CmdFlag=none
ReadOnFocus=0
BriefView=0
LeftActive=1
LeftPath=M:/bin/
RightPath=M:/test/
LeftSort=name
RightSort=ext
LeftSortDir=asc
RightSortDir=desc
LeftSortLfn=0
RightSortLfn=1
HideDrives=J,K,L
Viewer=texted.com
Editor=texted.com
