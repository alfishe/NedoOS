scrnet.com -- удаленный просмотр экрана NedoOS в браузере.

Не захватывает CRT (без SETGFX): nc, игры, zifi остаются на машине,
scrnet работает в фоне и отдаёт картинку по сети.

Сеть
----
/ini/network.ini, параметр currentNetwork:
  0 -- WIZNET (ZXNETUSB / W5300)
  2 -- ESPNET (бинарный UART к ESP, без AT-команд)
Любое другое значение: сообщение об ошибке и выход.

IP машины: myip.com или wizcfg.com. Порт HTTP -- 2324.

Подключение
-----------
На ПК в той же сети открой в браузере:

  http://<ip>:2324/

Кликни по картинке, чтобы слать клавиши на машину.
Right Shift+Enter или Ctrl+Enter -- смена графической задачи
(как Symbol Shift+Enter / Right Shift+Enter на клавиатуре).

Что передаётся
--------------
текст 80x25, Spectrum 256x192 (6912), EGA 320x200 x16, MC 640x200,
палитра DDp фокусной задачи.

WIZNET: сырые кадры (текст 4000 байт, EGA/MC 32K).
ESPNET: в тексте дельты XOR-RLE, в EGA/MC PackBits (UART примерно 10 КБ/с).
После смены режима (MC/EGA <-> текст) ESPNET шлёт полный ключевой кадр.

FPS
---
Файл /bin/scrnet/fps.ini (лимит 1-50, таймер 50 Гц):

  text=10
  scr=5
  ega=2

MC использует лимит ega. Страница в браузере читает fps.ini при загрузке.
Поля text / 6912 / ega в шапке меняют лимит на лету. Переподключение
потока /stream снова читает fps.ini на машине.
